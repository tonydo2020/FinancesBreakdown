Privacy Policy

Last updated: September 30, 2026

FinanceBreakdown is a private tool used only by the owner of the YouTube channel FinanceBreakdown to upload, schedule and manage videos on that channel and on the owner's own TikTok, Instagram and Facebook accounts. It is not offered to the public.

What it accesses

With the owner's permission through each platform's sign-in (OAuth 2.0), the tool uses the YouTube Data API to upload videos, thumbnails, captions and comments to the owner's own channel, the YouTube Analytics API to read that channel's statistics, the TikTok Content Posting API to upload videos to the owner's own TikTok account, and Meta's APIs to publish Reels to the owner's own Instagram and Facebook accounts. It does not access any other user's account or data.

What it stores

Sign-in tokens and channel statistics are stored only on the owner's personal computer. Nothing is stored on external servers, sold, or shared with third parties.

YouTube, Google and TikTok

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's Privacy Policy describes how Google handles data. TikTok's handling of data is described in the TikTok Privacy Policy.

Removing access and deleting data

Access can be revoked at any time: Google at myaccount.google.com/permissions or Google's security settings; TikTok under Settings and privacy → Security → Manage app permissions. Revoking access stops the tool immediately. Stored tokens and statistics can be deleted from the owner's computer at any time and are deleted when access is revoked.
